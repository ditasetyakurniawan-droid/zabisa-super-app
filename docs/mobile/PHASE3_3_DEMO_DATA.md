# Phase 3.3 - Full Development Demo Data

Phase 3.3 makes every **currently implemented** Zabisa module visibly populated in local development without introducing fake production behavior.

## Rule

All seed records are fictitious **DEVELOPMENT DATA** and are created through Zabisa HTTP APIs. The seed tooling:

- refuses any non-localhost `ZABISA_API_URL`;
- never writes directly to MySQL;
- uses real RBAC actors (`SUPER_ADMIN`, `GUARDIAN`, `USTADZ`, `GURU_AKADEMIK`);
- uses stable development keys/slugs so repeated runs are idempotent where the API allows it;
- does not fabricate FCM delivery, payment-gateway settlement, media upload, or production credentials.

### Public mobile / CMS

## Commands

```bash
npm run demo:seed
npm run demo:verify
```

or:

```bash
npm run demo:refresh
```

Then run the mobile app:

```bash
npm run mobile:device
```

No native rebuild is required for Phase 3.3 because this phase changes JavaScript, development tooling, and data only.
