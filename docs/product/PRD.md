# Zabisa Mobile MVP PRD

## Product goal
A trusted digital front door for public users, donors, guardians, teachers, and administrators of Zabisa. Public users browse verified CMS-driven information and donation campaigns. Guardians securely monitor linked students. Staff operate the system through a permissioned backoffice.

## MVP domains
Public content, kajian/events, donations, guardian-student linking, tahfidz progress, academic grades, attendance, reports, notification inbox/push, media metadata, RBAC, and audit trails.

## Non-functional requirements
Secure-by-default API, MySQL bounded-context ownership, OpenAPI contracts, structured logs, request IDs, meaningful tests, SonarQube quality gate, containerization, GitOps delivery, Vault secrets, and no fake production behavior.
